# 王佳润的个人 AI 档案

> 给任何 AI 的开场指令（复制下面这段话发给它即可）：
>
> 请读取这个仓库里的 USER.md、MEMORY.md、PREFERENCES.md 和 AGENTS.md，并把它作为你对我的长期记忆。今后每次对话都先以这些文件为上下文；对话中我告诉你的新事实、偏好或决定，请提醒我更新到对应文件里。

## 文件说明

- `USER.md`：我是谁、基本情况
- `MEMORY.md`：长期事实、目标、进行中的事
- `PREFERENCES.md`：我喜欢的沟通方式和回答风格
- `AGENTS.md`：希望 AI 怎样为我工作

## 安全说明

这个仓库是公开的，方便各家 AI 读取；因此里面**不含**手机号、邮箱、密码、证件号、家庭住址等敏感信息。需要保密的内容不要放进来。
