## 可信度标注说明

- ✅ **已确认**：用户本人说过，或已查证
- 🔶 **用户自述（未复核）**：用户自己说的，尚未经第三方验证
- ❓ **不确定**：信息不完整或存在冲突，读到时不要当成事实

## 安全说明

本仓库是公开的，方便各家 AI 读取；因此**不含**手机号、邮箱、密码、API 密钥、证件号、银行卡、家庭住址等敏感信息。需要保密的内容不要放进来。
